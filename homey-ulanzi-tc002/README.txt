Ulanzi TC002 (MQTT)

Send messages, icons and sounds from Homey to your Ulanzi TC002 running Awtrix 3, over MQTT.

Setup
1. Flash / configure Awtrix 3 on the TC002 and enable MQTT.
2. Note the MQTT prefix (example: awtrix_A1B2C3).
3. Install this app on Homey and add a Ulanzi TC002 device.
4. Enter your broker host/port/credentials and the MQTT prefix.

Flows
- Send notification (text + icon + sound + color)
- Custom apps, indicators, mood light, power, sounds/RTTTL
- Button press triggers and stats updates

Bundled icons: homey, message, warning, alert, info, check, bell, heart
Bundled sounds: beep, chime, notify, alarm, success, error, doorbell

You can also type icon/melody names that exist on the clock.
